# Essential Tiling

Редактор раскладки быстрых настроек Nothing OS. Модуль LSPosed меняет форму, размер и расположение плиток штатной шторки. Превью собирается из кадров SystemUI, а кнопки в шторке сохраняют штатные действия и состояния.

*An LSPosed Quick Settings layout editor for Nothing OS.*

## Возможности

- Перенос и изменение размера плиток, свободный поворот, Г-образные и диагональные формы, выступы, вырезы и порядок слоёв.
- Каталог системных плиток и TileService установленных приложений.
- Масштаб, интервалы и скругление, строка с данными батареи и размеры штатной Bluetooth-плитки.
- Предпросмотр, черновики, отмена и повтор, профили с импортом и экспортом в JSON.
- Действия TalkBack и клавиатурные сочетания для редактора.

## Совместимость

Модуль рассчитан на Nothing SystemUI 16.0.0 из исследованной прошивки Android 16. Для других сборок совместимость нужно проверять отдельно. Редактирование геометрии доступно в портретной ориентации. Нужен LSPosed с поддержкой Android 16 и legacy Xposed API. Приложению настроек отдельно выдавать root не требуется.

## Установка

1. Установите APK Essential Tiling.
2. Включите модуль в LSPosed и выберите область действия **SystemUI** (`com.android.systemui`).
3. Перезагрузите телефон. Полностью раскройте и закройте шторку, затем откройте редактор. При необходимости нажмите кнопку обновления над сеткой.
4. Чтобы записать изменения, нажмите **Применить**. Когда приложение предложит перезапуск SystemUI, подтвердите его.

При сообщении об ошибке укажите модель телефона, версию Nothing OS, версию модуля и шаги воспроизведения. Для ошибок хуков приложите отчёт модуля и относящийся к проблеме фрагмент журнала LSPosed с тегом `EssentialTiling`.
