# Essential Tiling

Редактор раскладки быстрых настроек Nothing OS. Модуль LSPosed меняет форму, размер и расположение плиток штатной шторки. Превью собирается из кадров SystemUI, а кнопки в шторке сохраняют штатные действия и состояния.

*An LSPosed Quick Settings layout editor for Nothing OS.*

## Возможности

- Перенос и изменение размера плиток, свободный поворот, Г-образные и диагональные формы, выступы, вырезы и порядок слоёв.
- Каталог системных плиток и TileService установленных приложений.
- Масштаб, интервалы и скругление, строка с данными батареи и размеры штатной Bluetooth-плитки.
- Предпросмотр, черновики, отмена и повтор, профили с импортом и экспортом в JSON.
- Действия TalkBack и клавиатурные сочетания для редактора.

## Совместимость

Модуль рассчитан на Nothing SystemUI 16.0.0 из исследованной прошивки Android 16. Для других сборок совместимость нужно проверять отдельно. Редактирование геометрии доступно в портретной ориентации. Нужен LSPosed с поддержкой Android 16 и legacy Xposed API. Приложению настроек отдельно выдавать root не требуется.

## Установка

1. Установите APK Essential Tiling.
2. Включите модуль в LSPosed и выберите область действия **SystemUI** (`com.android.systemui`).
3. Перезагрузите телефон. Полностью раскройте и закройте шторку, затем откройте редактор. При необходимости нажмите кнопку обновления над сеткой.
4. Чтобы записать изменения, нажмите **Применить**. Когда приложение предложит перезапуск SystemUI, подтвердите его.

### Переход с Nothing QS

Перед переходом экспортируйте нужные профили JSON из Nothing QS. Essential Tiling с идентификатором `moe.xWey10.tiling` устанавливается отдельно. Локальные настройки, черновики и библиотека профилей старого приложения автоматически не переносятся. Перед перезагрузкой отключите старый модуль в LSPosed, чтобы шторку менял только один модуль. Сохранённые профили можно импортировать. Для применения раскладки из профиля требуется совпадение состава плиток, страниц и сетки.

## Обновления

На главном экране появляется кнопка релиза, когда найдена более новая версия. Ручная проверка и переключатель автопроверки находятся в разделе **Модуль → Обновления**. Автопроверка при открытии включена по умолчанию и повторяется через сутки после успеха или через час после ошибки. Приложение обращается к GitHub Releases и открывает страницу релиза в браузере.

## Сборка

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Укажите путь к SDK через `ANDROID_HOME` или в локальном `local.properties`. Gradle Wrapper входит в репозиторий.

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:lintRelease
```

Готовый APK для локальной проверки появится в `app/build/outputs/apk/debug/app-debug.apk`.

```bash
./gradlew :app:assembleRelease
python3 scripts/verify_module_apk.py app/build/outputs/apk/release/app-release-unsigned.apk
```

Release собирается с R8 и без подписи. Для сборки и подписи своим ключом задайте путь к SDK, путь к локальному хранилищу ключей и псевдоним ключа.

```bash
ANDROID_HOME=/path/to/android-sdk \
KEYSTORE_PATH=/path/to/release.jks \
KEY_ALIAS=your-key-alias \
./scripts/build-signed-release.sh
```

Скрипт читает версию приложения и Build Tools из `app/build.gradle`. Пароли запрашивает `apksigner`. После проверки подписи APK появится в `dist/` под именем `Essential-Tiling-v<version>.apk`. Для обновлений используйте тот же ключ. Скрипты проверки требуют Python 3.11+.

Для проверки обновлений публикуйте стабильный GitHub Release в `xWey10/Essential-Tiling` с тегом вида `v0.12.2` и прикладывайте подписанный APK.
